# FRONTLINE ZERO｜零号前线

**3D 第一人称战术射击游戏原型。** 当前版本为 V0.1，采用 Three.js + WebGL，场景与角色均由程序化几何体构建，不依赖外部模型素材。

## 当前可玩内容

- 第一人称视角、WASD 移动、鼠标观察、冲刺、跳跃。
- 三种可切换武器：手枪、突击步枪、精确射手步枪。
- 射击、命中检测、头部伤害倍率、弹药、换弹、瞄准与后坐力反馈。
- 8 名敌方单位，具备推进、侧移、射击和低血量撤向掩体的基础行为。
- 城市街区战场、低矮掩体、集装箱、废弃车辆、路灯、碎石与雾效。
- 血量、弹药、击杀数、任务完成/失败结算。
- 触屏移动、观察、瞄准、开火和换弹的基础操作界面。
- 使用 Web Audio 合成基础射击、命中和受伤提示音。

## 运行

需要可访问 jsDelivr CDN 的现代浏览器。项目不需要 npm 安装依赖。Node.js 仅用于运行源码检查与单元测试。

### Windows

双击 `run.bat`，然后打开 `http://127.0.0.1:8000`。

运行源码检查与测试：

```bash
npm run check
npm test
```

也可以在项目目录执行：

```powershell
py -m http.server 8000
```

### macOS / Linux

```bash
python3 -m http.server 8000
```

然后打开 `http://127.0.0.1:8000`。

> 由于浏览器 ES Module 与跨域限制，不建议直接双击 `index.html`。Three.js 当前通过固定版本 CDN 加载；离线环境暂不支持。

## 桌面端操作

| 输入 | 功能 |
|---|---|
| W / A / S / D | 移动 |
| 鼠标 | 观察与瞄准 |
| 鼠标左键 | 射击（按住可连续射击） |
| 鼠标右键 | 精确瞄准 |
| R | 换弹 |
| 1 / 2 / 3 | 切换武器 |
| Shift | 冲刺 |
| Space | 跳跃 |
| ESC | 释放鼠标并暂停观察；点击画面继续 |

## 移动端操作

左下方向键移动，右侧拖动区域转动视角，右下按钮用于瞄准、换弹、切换武器和开火。移动端适配目前属于原型级，仍需真实 Android 设备验收。

## 研发状态

- 当前：V0.1 可玩原型源码。
- 自动化校验：`npm run check` 与 `npm test`，覆盖核心伤害、换弹、爆头倍率、任务状态和 HTML/JS 引用。
- 已完成：基础场景、第一人称控制、三种武器、基础敌人 AI、HUD、胜负流程。
- 未完成：真实浏览器 WebGL 验收、Android 触控验收、音画质量验收、性能基准、完整武器动画、敌人掩体寻路与关卡平衡。
- 不将程序化几何体演示等同于最终美术质量；不将自动化静态检查等同于真人试玩验收。
